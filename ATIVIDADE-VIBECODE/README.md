# Henrique Lira · Consultoria de Investimentos

Landing page da atividade de vibecode (Front-End, FIAP). Persona fictícia, exercício acadêmico: nenhum formulário envia dados e todos os números de clientes são fictícios.

## Como abrir
Abra `index.html` no navegador (duplo clique). Para servir localmente:

```
py -m http.server 8080
```
e acesse http://127.0.0.1:8080/

## O que tem na pasta

- `index.html`, `css/` e `js/`: a página, em HTML, CSS e JavaScript puros, sem build.
- `img/`: fotos livres do Unsplash (autor e licença em `processo/03-referencias-visuais.md`); ilustrações e ícones são SVG autorais, dentro do HTML.
- `processo/`: o processo da atividade.
- `prints-referencias/`: prints dos sites de referência (Mercury, Warren, Nord, Betterment e Wealthfront).

| Arquivo | Conteúdo |
|---|---|
| `processo/01-prompts.md` | Os prompts de cada etapa, regras globais, riscos testados, o que a IA entregou e o que foi corrigido |
| `processo/02-pesquisas.md` | Regras da CVM, confiança, acessibilidade e licenças, com fonte e grau de confiança |
| `processo/03-referencias-visuais.md` | Referências visuais vistas, o que foi adotado, e fotos com autor e licença |
| `processo/04-decisoes-de-design.md` | A ideia, conceito, decisões com alternativas descartadas, o que a página não faz, critérios de pronto e estrutura da página |
| `processo/05-paleta-de-cores.md` | Paleta com contraste calculado e tipografia |
